# Azure Buddy — Your AZ-900 Study Companion

**Azure Buddy** is a learner-friendly web application designed to help students prepare for the Microsoft Azure Fundamentals (AZ-900) certification exam.

The platform makes studying easier through organized learning materials, practice quizzes, flashcards, and progress tracking.

## 🌐 Live Demo

[Try Azure Buddy](https://scene-by-scene-style.lovable.app)

## ✨ Features

* **📚 Learn:** Explore key AZ-900 topics, including cloud concepts, Azure architecture and services, and management and governance.
* **📝 Practice Quizzes:** Test your understanding with practice questions.
* **🗂️ Flashcards:** Review important Azure concepts and terminology.
* **🔄 Mistake Review:** Revisit questions you answered incorrectly and strengthen your understanding.
* **📊 Progress Tracking:** Monitor your learning progress.
* **📅 Study Planner:** Organize your revision sessions.
* **🎯 Exam Readiness:** Review your preparation progress.
* **💬 Study Buddy:** Access helpful study guidance and answers to common questions.

## 🎯 Purpose

Azure Buddy aims to make AZ-900 preparation more accessible, organized, and engaging, especially for learners who are new to cloud computing.
